CryptoEntropy-Analyzer 🔒

Edukativni Java alat namenjen studentima i entuzijastima za istraživanje i vizuelno razumevanje 
Shannon-ove entropije i nasumičnosti podataka pre i posle 128-bitne AES enkripcije.

📌 O projektu

CryptoEntropy-Analyzer je razvijen s primarnim ciljem da pomogne studentima i istraživačima da lakše shvate kako kriptografska entropija funkcioniše u praksi. 
Kroz rad sa alatkom može se uočiti važan teorijski i praktični koncept: entropija nije uvek veća nakon svakog šifrovanja — u zavisnosti od 
strukture i sadržaja ulaznih podataka, ona se u određenim slučajevima može i smanjiti. 
Ovaj alat služi kao praktično okruženje za testiranje i demistifikaciju ponašanja podataka pod AES enkripcijom. 

✨ Ključne karakteristike

*Edukativni pristup: Idealno za razumevanje osnova teorije informacija, nasumičnosti i kriptografije.

*Analiza Šenonove Entropije: Izračunavanje i upoređivanje vrednosti entropije pre i nakon procesa šifrovanja fajlova.

*Praktičan uvid: Demonstracija specifičnih slučajeva gde se nivo entropije menja suprotno očekivanjima (npr. kod specifičnih struktura podataka).

*Jednostavna upotreba: Pregledan Java interfejs prilagođen brzom testiranju različitih tipova fajlova.
